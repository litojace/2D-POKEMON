# Legacy articulated boss source

These original source paintings and `scripts/export-boss-parts.py` are preserved
for art history. The runtime no longer loads their atlases or assembles bosses
from these separate parts.

The current renderer uses [complete creature poses](../whole/README.md), which
keep heads, necks and shoulders connected inside each authored image. Use
`scripts/export-whole-bosses.py` for current runtime exports.
