# Showcase portrait generation

Generated with the built-in image_gen tool, using the user's Element Arena Creature Showcase and the first rendered Voltkit image as references. These are static transparent portraits, not directional animation frames. Final WebP assets preserve alpha and use lossless encoding without resizing or repainting. Native PNG outputs remain in the Codex generated-images folder.

Final assets: apps/client/public/assets/fighters/{fighterId}/portrait-showcase-v1.webp.
