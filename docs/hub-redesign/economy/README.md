# Economy model

These are Python models behind the XP, coin and Gold Leaf numbers in the prototype. Run them from this folder with `python3 <file>`.

| File                                                               | Status    | What it does                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `player_curve.py`                                                  | **final** | Account level curve 1–100 (`xp_next`). Lv 1–50 are exactly the live curve; matches `xpNext` in `prototype/app/progress.js`.                                                                                                                                                  |
| `farm_curve.py`                                                    | **final** | Farm level curve 1–100 (`a = 2.418`, `b = 2.1`); matches `need` in `prototype/app/farm.js`.                                                                                                                                                                                  |
| `econ_final.py`                                                    | **final** | Collects every final number into `data.json`.                                                                                                                                                                                                                                |
| `report_data.py` → `build_report.py`                               | **final** | `report_data.py` writes the chart data (`report_data.json`); `build_report.py` fills `report.tpl.html` with it to make `kinh-te.html`, the Vietnamese report published at https://claude.ai/artifact/PNGPNFVKBqxtuGzJ9FCJre. It reproduces the published page byte for byte. |
| `farm_model.py`                                                    | model     | Daily XP and leaves for casual, regular and hardcore players by farm level. `farm_curve.py` uses it.                                                                                                                                                                         |
| `player_model.py`                                                  | **draft** | First pass. Its `new_next` curve was replaced by `player_curve.py`; only `ARCH` and `per_active_day` are still used.                                                                                                                                                         |
| `fit_player.py`, `fit_player2.py`                                  | draft     | Curve fitting used while choosing `player_curve.py`.                                                                                                                                                                                                                         |
| `data.json`, `player_fit.json`, `farm_fit.txt`, `report_data.json` | output    | Saved outputs of the scripts above.                                                                                                                                                                                                                                          |

If a number here and the prototype source ever disagree, trust the source.
`NUMBERS.md` one folder up is generated from the source with `prototype/app/numbers.js`.
